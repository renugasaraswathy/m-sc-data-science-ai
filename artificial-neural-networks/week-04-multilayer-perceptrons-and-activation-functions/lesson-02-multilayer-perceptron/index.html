The Multilayer Perceptron¶

Key Concepts¶

1. What is a Multilayer Perceptron (MLP)¶

Definition¶

  • An MLP is a feed-forward neural network made of three kinds of layers: an input layer, one or more hidden layers, and an output layer.
  • Information flows strictly one way: input → hidden → output. No cycles, no feedback connections — that is what "feed-forward" means.
Layer Role
Input Holds the raw feature vector. No computation — just a container
Hidden Where the transformations happen; takes the previous layer's output and produces a new representation
Output Takes the last hidden representation and produces the final prediction

Fully connected architecture¶

  • In a standard MLP every neuron in one layer sends its output to every neuron in the next layer.
  • Example: 2 inputs (x₁, x₂) → hidden layer of 3 → hidden layer of 3 → 1 output y.
flowchart LR
    x1["x₁"] --> h1["h₁"] & h2["h₂"] & h3["h₃"]
    x2["x₂"] --> h1 & h2 & h3
    h1 & h2 & h3 --> g1["g₁"] & g2["g₂"] & g3["g₃"]
    g1 & g2 & g3 --> y["y"]

Parameter count in a dense network¶

  • Parameters = weights (one per connection) + biases (one per neuron, not per connection).
  • Example: 3 neurons → 2 neurons = 6 weights + 2 biases = 8 parameters; 3 → 3 = 9 weights + 3 biases = 12 parameters. (The lecturer first counted a bias per connection, then corrected it: a neuron has one bias, z = w₁x₁ + w₂x₂ + w₃x₃ + b.)
  • Every added neuron or layer multiplies the count → dense networks have a very high parameter count. The upside is the capacity to model complex relationships.
  • Each neuron emits one value as output. The weights belong to the connections; the input-layer "neurons" do nothing — they just hold the feature values.

What a layer computes¶

  • Every layer has a weight matrix W and a bias vector b — these parameters define the function the network computes.
  • Each layer does two things:
    1. Linear transformation: z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
    2. Nonlinear activation: a⁽ˡ⁾ = f(z⁽ˡ⁾)
  • a⁽ˡ⁻¹⁾ is the previous layer's output; a⁽ˡ⁾ is a new representation of the data and becomes the input to the next layer.
  • Notation: the superscript ⁽ˡ⁾ only says which layer a quantity belongs to — it is not a power. Everything is a vector or matrix: z⁽ˡ⁾ is the vector (z₁, z₂, z₃) of the layer's neurons, W⁽ˡ⁾ is a matrix (one row per neuron in layer l).
  • a⁽ˡ⁻¹⁾ is the post-activation output of the previous layer, so what flows into layer l+1 is a⁽ˡ⁾, not z⁽ˡ⁾.
  • Where weights and biases come from: they start as random values and are learned during training. Hidden layers never see the target output; the flow is: forward pass with current weights → compare the prediction with the actual value → go back through the network (chain rule, backpropagation — next class) → update all weights and biases, including the hidden ones. Training even a small network is computationally heavy (hence GPUs).
flowchart LR
    A["a⁽ˡ⁻¹⁾<br/>previous layer output"] --> B["z = W·a + b<br/>linear"]
    B --> C["a = f(z)<br/>activation"]
    C --> D["a⁽ˡ⁾<br/>input to next layer"]

Shapes in a small example¶

  • Input has 2 features, hidden layer has 3 neurons, output layer has 1 neuron.
Item Shape
Input x 2 × 1
W₁ (hidden) 3 × 2
b₁ 3 × 1
W₁x + b₁ → a₁ 3 × 1
W₂ (output) 1 × 3
W₂a₁ + b₂ → output 1 × 1
  • Inner dimensions must match (3×2 times 2×1 ✓; 1×3 times 3×1 ✓).
  • ★ The representation's dimension changes layer by layer — the network isn't just classifying, it is reshaping the feature space at each layer.

An MLP is a composition of functions¶

  • Not one big formula but many simple transformations stacked: a⁽ᴸ⁾ = f_L( f_{L−1}( … f₁(x) … ) )
  • Each layer refines the representation a little further; this repeated transformation is the source of the power of multilayer networks, and why MLPs are the core template for deep networks.

2. Role of Hidden Layers in Representation¶

Why hidden layers¶

  • A single layer can only learn linear transformations, however many neurons it has — so only linear decision boundaries.
  • Real-world relationships (images, speech, medical, financial data) are highly nonlinear. Hidden layers re-encode the data into internal representations in which complex patterns are easier to separate.

Representation learning¶

  • Representation = how the data is encoded inside the network. The raw input (pixels, table values) is the first representation; each hidden layer gives a new one.
  • Example (house price): inputs bedrooms and size together imply spaciousness. Spaciousness is not an input feature — it is abstract information learned in a hidden layer.
  • ★ Learning isn't only about learning a classifier — it is also about learning better internal representations.

Hidden neuron as a feature detector¶

  • A hidden neuron computes a = f(wᵀx + b) and responds strongly when a specific pattern appears in the input.
  • Different neurons detect different patterns; together they form a bank of feature detectors.
Raw features Derived features
What Direct measurements (e.g. pixel intensities) Created by hidden layers
Captures Little on their own Combinations, interactions between inputs, structural patterns
  • Each new layer works on features from the previous layer, not on the original input. No extra input enters the hidden layers — the original features are fed only once, at the input layer.
  • Each hidden neuron is one more combination f(w₁x₁ + w₂x₂ + b) of the same inputs, so more neurons = more latent representations of the input (similar in spirit to the components PCA extracts).

Hierarchical representation learning¶

flowchart LR
    A["Input<br/>raw pixels"] --> B["Hidden layer 1<br/>edges"]
    B --> C["Hidden layer 2<br/>corners, contours"]
    C --> D["Deeper layers<br/>shapes, objects"]
    D --> E["Output<br/>dog / cat / bird"]
  • Early layers learn simple patterns (edges, basic numeric trends); deeper layers combine them into shapes, objects, abstract concepts.
  • ★ One central reason deep networks beat shallow ones.

The trade-off¶

  • More hidden neurons → more feature detectors. More hidden layers → more levels of abstraction. Together: a much larger set of representable functions.
  • But also: more parameters, more computational cost, higher risk of overfitting. Managed later via training and regularisation.
  • Overfitting = the model starts learning noise or random patterns in the data instead of the real ones.
  • How many layers / neurons? There is no right answer; it depends mainly on how much data you have (more data supports more complex networks). In practice it is trial and error: start small and simple, then grow while watching the training and validation curves for overfitting.

XOR revisited¶

  • XOR fails for a perceptron because no single line separates it.
  • Hidden neurons create multiple intermediate splits of the input space; with the changed representation the two classes become separable.
  • ★ Changing the representation in a hidden layer turns a linearly impossible problem into a solvable one. XOR is the smallest example of what all deep networks do.

3. Forward Pass in an MLP¶

Definition¶

  • A forward pass = executing the stored computations of a (trained) network on a single input to produce a prediction. Every prediction comes from a forward pass.

Inside one neuron (4 steps)¶

  1. Multiply each input by its weight.
  2. Sum the weighted inputs.
  3. Add the bias.

  4. Apply the activation function: z = Σ wᵢxᵢ + b, a = f(z).

  5. Pure numerical computation at run time — no learning happens.

Layer by layer¶

flowchart LR
    X["Input x"] --> L1["Hidden layer 1<br/>a₁ = f(W₁x + b₁)"]
    L1 --> L2["Hidden layer 2<br/>a₂ = f(W₂a₁ + b₂)"]
    L2 --> O["Output layer<br/>task-specific prediction"]
  • ★ The original input is never used again directly; each layer only sees the transformed representation from the previous one.
  • All neurons within a layer compute in parallel.

What a neuron is in memory (and in LLM training)¶

  • A "neuron" is not a thread, process or object. It is one row of the layer's weight matrix W plus one entry of the bias vector b: just numbers stored in an array (on a GPU). Its activation is one entry of the result array.
  • A whole layer is computed by one matrix operation, not a loop over neurons:
z = W @ a_prev + b    # all neurons in the layer at once
a = relu(z)           # activation applied to all of them
  • The GPU splits that multiplication into many small tiles of multiply-add work, so the parallelism is in the arithmetic, not "one thread per neuron". This is why GPUs suit neural networks.
  • A saved model (e.g. an LLM's 70 GB file) is just these weight and bias arrays.
  • Training step = forward pass (matrix operations) → one loss number → backward pass (more matrix operations, giving a gradient array shaped like each W) → the optimizer adjusts every number in W slightly (W ← W − lr · gradient) → repeat.
  • Huge models don't fit on one GPU, so the arrays are split: data parallelism (each GPU holds a full copy and sees different data), tensor parallelism (one matrix cut across GPUs), pipeline parallelism (different layers on different GPUs).
  • "Neuron" is a way of thinking about one row of the table (take inputs, weigh them, fire); the code never loops over neurons one at a time.

What the output layer produces¶

Task Output
Binary classification A probability
Multi-class classification Class scores / probabilities
Regression A real-valued number

Why it matters¶

  • The forward pass is the core computation of a network (image recognition, recommenders, medical diagnosis…).
  • Training repeats the same forward computation, then adjusts weights using the errors observed; backpropagation (later module) changes parameters and affects the next forward pass.
  • ★ Prediction (inference) is one-directional only (feed-forward). Going backwards through the network happens only during training, to update the weights.

4. Expressive Power of MLPs¶

Definition¶

  • Expressive power = the set of functions a model can represent (its capacity) — not yet about training or performance.
  • Controlled by two structural choices: depth (number of layers) and width (neurons per layer).

Shallow vs deep¶

  • Shallow: one hidden layer or none. Deep: multiple stacked hidden layers.
  • Both can in principle approximate complex functions; they differ greatly in efficiency.
Width (more neurons, one layer) Depth (more layers)
Effect More feature detectors at one level of abstraction → finer partitions of input space Hierarchical composition: simple features first, combined into complex ones
Cost Neurons needed may grow exponentially Many functions need far fewer parameters

Universal approximation theorem¶

  • A network with even one hidden layer can approximate any continuous function, given enough neurons.
  • ★ Catch: the number of neurons required may be exponentially large — impractical.

Why depth wins in practice¶

  • Deep, narrower networks are far more parameter-efficient — same class of functions with fewer neurons and parameters.
  • Real problems are hierarchical: vision (edges → shapes → objects); language (characters → words → phrases → meaning). Deep networks match this composition, which is why they're so effective for vision, speech and language.
  • Modern design favours depth over extreme width.
  • Example: one hidden layer of 100 neurons can do the same job as a few small stacked layers, but needs far more parameters. That depth is more efficient is shown empirically (experiments), not proven.
  • Analogy: it mirrors how people learn — basic concepts first, then build on them — rather than learning everything in one step. Each layer re-composes the previous layer's output instead of trying to fit everything with one huge set of weights.
