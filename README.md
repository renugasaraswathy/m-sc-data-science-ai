# M.Sc Data Science & AI — Learning Notes

Organized lecture notes from video courses, restructured, simplified, and visualized
with Claude. Published as a browsable site via [MkDocs](https://www.mkdocs.org/) and
GitHub Pages.

## Structure

Notes live under `docs/`, one folder per course, one subfolder per week, one file per
lesson:

```
docs/
  machine-learning/
    week-01-introduction-to-machine-learning/
      lesson-01-machine-learning-paradigms-and-workflow.md
```

See [`CLAUDE.md`](CLAUDE.md) for the full note-taking workflow and lesson template.

## Local preview

```
pip install -r requirements.txt
mkdocs serve
```
