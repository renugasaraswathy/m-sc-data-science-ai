# Cloud Service Models

## Key Concepts

### IaaS, PaaS, SaaS

| | IaaS | PaaS | SaaS |
|---|---|---|---|
| Provider gives | VMs, storage, network, load balancers, compute infra | Infra + security patching + runtime + environment + scaling | A complete software product, ready to use |
| You manage | Everything on top of the raw infra — OS, security config, etc. | Just write and run your application code | Nothing — you just use it |
| Analogy | Renting an empty apartment | Renting a furnished apartment | Staying in a hotel |
| Examples | Virtual machines | Elastic Beanstalk | Gmail, Zoom |
